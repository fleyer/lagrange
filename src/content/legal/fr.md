<h2 id="confidentialite">Politique de confidentialité</h2>

### Données collectées

Ce site peut collecter des données anonymisées via Google Analytics (Google Tag Manager), uniquement si vous avez accepté les cookies. Ces données incluent : pages visitées, durée de visite, type d'appareil et pays. Votre adresse IP est anonymisée.

Les messages envoyés via le formulaire de contact (nom, email, message) sont transmis directement par email et ne sont pas stockés sur un serveur tiers.

### Base légale

- Analyse d'audience : votre consentement (recueilli via le bandeau cookies).
- Données de contact : nécessité contractuelle pour répondre à votre demande.

### Conservation des données

- Données analytiques : 14 mois (paramètre par défaut Google Analytics).
- Données de contact : jusqu'à la clôture de l'échange.
